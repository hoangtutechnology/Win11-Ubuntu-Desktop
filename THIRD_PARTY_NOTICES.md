# Third-party components

This repository is an integration and customization project by `hoangtutech`. The components below retain their original source identity, authorship notices, and license terms.

## ArcMenu

- Upstream: [ArcMenu for GNOME](https://gitlab.com/arcmenu/ArcMenu)
- Its code is bundled under GPL-2.0; the upstream license and README remain in `extensions/arcmenu@arcmenu.com/`.
- The GNOME extension ID remains `arcmenu@arcmenu.com` because GNOME settings and the extension schema use it. Its display name is branded as **HoangTuTech Win11 Start Menu**.
- The Windows-style menu, search, Task View, tray, and integration customizations in this fork are by `hoangtutech`.

## GTK theme

- The bundled Fluent Light Compact theme files are based on [Fluent GTK Theme](https://github.com/vinceliuice/Fluent-gtk-theme), which in turn uses Materia theme styling.
- The local package is named **HoangTuTech-Win11**. Its upstream GPL-3.0 license is retained in `assets/themes/HoangTuTech-Win11/COPYING`.
- SVG artwork inside the theme retains its embedded author and CC BY-SA 4.0 notices.

## Separate dependencies

- [Fluent icon theme](https://github.com/vinceliuice/Fluent-icon-theme)
- Dash-to-Panel GNOME extension
- Bibata-Modern-Classic cursor theme

These dependencies are not bundled here and remain under their respective upstream licenses.
