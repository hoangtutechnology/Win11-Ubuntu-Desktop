# HoangTuTech Menu

HoangTuTech Menu provides a Windows-style Start menu for GNOME. This customized build includes the Windows 11 layout, search, Task View, and taskbar tray overflow used by the Win11-Ubuntu-Desktop project.

The extension keeps GNOME's existing identifier, `arcmenu@arcmenu.com`, and settings schema for compatibility. Its upstream base is ArcMenu 73; see [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md) for source, authorship, and license details. The upstream license is in [`LICENSE`](LICENSE), and the original project documentation is preserved in [`UPSTREAM_README.md`](UPSTREAM_README.md).

Install and configure the complete desktop setup with the repository's [`install.sh`](../../install.sh). Avoid installing this source folder directly as a GNOME extension: the installed folder must use the GNOME identifier above.
